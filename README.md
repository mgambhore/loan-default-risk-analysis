# Loan Default Analysis | Python & Power BI

## Project Overview
This project analyzes loan data to understand loan default patterns and identify borrower and loan characteristics associated with default. Python was used for data preparation and exploratory analysis, while Power BI was used to create an interactive dashboard.

## Business Problem
Lending companies face financial risk when borrowers fail to repay their loans. Analyzing historical loan data can help identify patterns associated with defaults and support better loan portfolio monitoring.

## Project Objectives
- Analyze overall loan performance and default distribution.
- Examine default rates across loan grades and loan purposes.
- Investigate relationships between home ownership, interest rates, and credit history length with loan defaults.
- Develop an interactive Power BI dashboard for monitoring key loan metrics.
- Present data-driven insights to support business decision-making.

## Project Workflow
1. Data understanding and quality assessment
2. Data cleaning and preparation
3. Exploratory data analysis using Python
4. Loan default analysis across key categories
5. Interactive dashboard development in Power BI
6. Business insights and recommendations

## Dashboard
The dashboard presents key performance indicators and visualizations covering:
- Total loans and defaulted loans
- Loan default distribution
- Default rate by loan grade
- Default patterns by loan purpose
- Default rate by home ownership
- Credit history length analysis
- Interest rate analysis

## Key Deliverables
- Python analysis notebook
- Cleaned dataset, subject to its license
- Interactive Power BI dashboard
- Project documentation

## Limitations
This project analyzes observed historical loan outcomes. The relationships identified are descriptive and do not establish causation. The analysis is not a production credit-scoring model and should not be used independently to make lending decisions.
